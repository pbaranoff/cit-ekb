# СиАйТи — вёрстка сайта

Адаптивная статическая вёрстка сайта контейнерного терминала СиАйТи. В проект входят главная страница и страница «Информация о компании».

## Просмотр

Откройте `index.html` или `about.html` в браузере. Чтобы проверить страницы через локальный сервер, выполните в корне проекта:

```sh
python3 -m http.server 8766
```

Затем откройте [главную страницу](http://localhost:8766/index.html) или [информацию о компании](http://localhost:8766/about.html).

## Исходники

- `src/pages/` — HTML-исходники страниц.
- `src/partials/` — общие шапка, боковая панель, меню и контакты.
- `assets/css/` и `assets/js/` — стили и интерактивность страниц.
- `assets/images/`, `assets/icons/`, `assets/fonts/` — изображения, иконки и шрифты.

Общие HTML-фрагменты подключены в исходниках маркерами `include`. Чтобы собрать из них готовые `index.html` и `about.html`, нужен Node.js:

```sh
node scripts/build.mjs
```

Готовые страницы не требуют сборщика и JavaScript-зависимостей для отображения.
