# СиАйТи — вёрстка сайта

Адаптивная статическая вёрстка сайта контейнерного терминала СиАйТи. В проект входят главная, «Информация о компании» и «Пресс-центр» с детальной страницей материала.

## Просмотр

Откройте `index.html`, `about.html` или `press.html` в браузере. Чтобы проверить страницы через локальный сервер, выполните в корне проекта:

```sh
python3 -m http.server 8766
```

Затем откройте [главную страницу](http://localhost:8766/index.html), [информацию о компании](http://localhost:8766/about.html) или [пресс-центр](http://localhost:8766/press.html).

## Исходники

- `src/pages/` — HTML-исходники страниц.
- `src/partials/` — общие шапка, боковая панель, меню и контакты.
- `assets/css/` и `assets/js/` — стили и интерактивность страниц.
- `assets/images/`, `assets/icons/`, `assets/fonts/` — изображения, иконки и шрифты.

Общие HTML-фрагменты подключены в исходниках маркерами `include`. Чтобы собрать из них готовые HTML-страницы, нужен Node.js:

```sh
node scripts/build.mjs
```

Готовые страницы не требуют сборщика и JavaScript-зависимостей для отображения.

## Состояние проекта

Ссылки на другие разделы подготовлены для будущих страниц. Поиск контейнера и отправка заявок требуют подключения к серверу сайта.

Карточка «C.I.T. представил опыт цифровизации в логистике» открывает локальную страницу `digital-logistics.html`. Остальные материалы ведут на cit-ekb.ru. Выбор года и номера страницы ведёт в архив на том же сайте.
